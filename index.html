      How it works

      Old way

      Count the keywords

      Split each page into words, count how many times the search words appear, and show the highest count first.

      The problem: anyone can cheat. Page 6 just repeats “pizza” ten times, so it wins every pizza search even though it is useless.

      PageRank

      Count the votes

      A link is a vote. Every page starts with an equal share (1/6). On each round, a page passes its score along its outgoing links, split equally.

      PR(A) = (1 − d) / N + d × Σ PR(B) / L(B)

      d = 0.85 (damping), N = 6 pages, L(B) = number of links on page B. We repeat until the scores stop changing (– rounds).

      Page 6 has no pages linking to it, so it keeps only the minimum score and drops to the bottom.
